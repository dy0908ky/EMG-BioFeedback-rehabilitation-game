# EMG 다마고치 바이오피드백 게임

근전도(EMG) 신호를 이용해 OLED 화면 속 캐릭터를 계단 위로 이동시키는 Arduino 기반 바이오피드백 게임입니다. 사용자가 기준 근력의 85% 이상을 발휘하면 캐릭터가 한 단계 올라가고, 그렇지 않으면 한 단계 내려갑니다.

## 프로젝트 개요

근육의 활성도를 숫자로만 보여주는 대신, 캐릭터의 움직임과 표정, LED 색상으로 결과를 즉시 전달하도록 설계했습니다. 게임 시작 시 사용자별 기준값을 측정하기 때문에 절대적인 센서값이 아닌 개인화된 목표값으로 플레이할 수 있습니다.

## 주요 기능

- 3초 동안 사용자의 기준 EMG 신호 측정
- 기준값의 85%를 각 trial의 성공 목표로 설정
- 3초 측정 구간에서 최댓값 대비 70~90%에 해당하는 표본의 평균 사용
- 총 6회의 trial 진행
- 성공 시 레벨 상승, 초록색 LED 점등 및 웃는 표정 표시
- 실패 시 레벨 하락, 빨간색 LED 점등 및 무표정 표시
- 최종 레벨이 4 이상이면 `WIN`, 미만이면 `LOSE` 표시
- 시리얼 모니터에서 측정값, 목표값, 최댓값 확인 가능

## 하드웨어

| 부품 | 수량 | 용도 |
| --- | ---: | --- |
| Arduino Uno R3 | 1 | 센서 입력 처리 및 전체 시스템 제어 |
| EMG 센서 | 1 | 근전도 신호 측정 |
| 0.96인치 I2C OLED (SSD1306, 128×64) | 1 | 게임 화면 출력 |
| 빨간색 LED | 1 | trial 실패 표시 |
| 초록색 LED | 1 | trial 성공 표시 |
| 220Ω 저항 | 2 | LED 전류 제한 |

EMG 센서가 없어도 포텐셔미터를 A0에 연결해 입력 동작을 시험할 수 있습니다.

## 배선

| 장치 | 장치 핀 | Arduino 핀 |
| --- | --- | --- |
| OLED | VCC | 5V |
| OLED | GND | GND |
| OLED | SDA | A4 |
| OLED | SCL | A5 |
| EMG 센서 | Signal | A0 |
| 빨간색 LED | Anode (+) | D7 (220Ω 저항 사용) |
| 초록색 LED | Anode (+) | D8 (220Ω 저항 사용) |

각 LED의 cathode(-)는 GND에 연결합니다. 사용 중인 EMG 센서 모듈의 허용 전압과 제조사 배선 지침을 먼저 확인하세요.

## 게임 진행 방식

1. OLED에 기준값 측정 안내와 3-2-1 카운트다운이 표시됩니다.
2. 3초 동안 기준 EMG 값(`REF`)을 측정합니다.
3. `REF × 0.85`를 성공 목표값으로 설정합니다.
4. 각 trial에서 3초 동안 EMG 신호를 측정합니다.
5. 측정값이 목표값 이상이면 캐릭터가 올라가고, 미만이면 내려갑니다.
6. 6회의 trial이 끝난 뒤 최종 레벨에 따라 승패를 표시합니다.
7. 결과 표시 후 새로운 게임이 자동으로 시작됩니다.

```text
기준값 측정 → 목표값 계산 → 6회 trial → 최종 레벨 판정 → 재시작
```

## 측정 로직

Arduino는 A0의 아날로그 입력을 20ms 간격으로 3초간 읽습니다. 측정 중 확인된 peak의 70~90% 범위에 들어온 표본을 모아 평균을 계산합니다. 유효 표본이 3개 미만이면 `peak × 0.80`을 대체값으로 사용합니다.

```text
threshold = reference measurement × 0.85

trial measurement >= threshold  → 성공, level + 1
trial measurement < threshold   → 실패, level - 1
```

레벨은 0~7 범위로 제한됩니다.

## 개발 환경 및 라이브러리

- Arduino IDE
- `Wire` (Arduino 기본 라이브러리)
- `Adafruit GFX Library`
- `Adafruit SSD1306`

Arduino IDE의 라이브러리 관리자에서 `Adafruit GFX Library`와 `Adafruit SSD1306`을 검색해 설치할 수 있습니다.

## 실행 방법

1. 저장소를 내려받습니다.
2. Arduino IDE에서 [`EMG.ino`](./EMG.ino)를 엽니다.
3. 필요한 Adafruit 라이브러리를 설치합니다.
4. **Tools > Board**에서 `Arduino Uno`를 선택합니다.
5. 연결된 포트를 선택하고 코드를 업로드합니다.
6. 디버깅이 필요하면 baud rate를 `115200`으로 설정해 시리얼 모니터를 엽니다.

Arduino IDE가 스케치 폴더 생성을 요청하면 `EMG/EMG.ino` 구조가 되도록 허용합니다.

## 주요 설정값

[`EMG.ino`](./EMG.ino) 상단의 상수를 수정해 게임 난이도와 진행 방식을 조정할 수 있습니다.

| 상수 | 기본값 | 의미 |
| --- | ---: | --- |
| `MAX_LEVEL` | 7 | 캐릭터의 최대 레벨 |
| `TOTAL_TRIAL` | 6 | 한 게임의 측정 횟수 |
| `WIN_LEVEL` | 4 | 승리 판정에 필요한 최소 레벨 |
| `MEASURE_MS` | 3000 | 회당 측정 시간(ms) |
| `MEASURE_INTERVAL` | 20 | 센서 표본 간격(ms) |
| `DEBUG` | `true` | 시리얼 디버그 출력 여부 |
